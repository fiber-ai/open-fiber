# OpenFiber — Impeccable audit (FIB-20648)

Run: 2026-10-22 · impeccable 4.7.0 (engine 0.1.16) · `/impeccable audit` on `nextjs/`

## Implementation Integrity Verdict

**Fail.** The token architecture is sound (HSL CSS variables, `cn()` + CVA, Radix primitives), but every value in it is the shadcn starter palette: pure grayscale, black primary button, `0.5rem` radius, no typeface set (`font-sans` falls back to the system stack while Inter downloads unused). The wordmark is plain text and the favicon is three generic lines. Swap the name and this could be any SaaS admin template — the "AI slop" tell the ticket is about. Status colour is expressed with raw Tailwind palette classes (`bg-green-100 text-green-800`, `text-amber-600`, `bg-blue-600`) in 26 files instead of tokens, so the theme can't be changed in one place, which contradicts the README's "fork it, restyle it" promise.

Detector: 1 source finding (`overused-font`: Inter, `_document.tsx:9`), 5 rendered `skipped-heading`, 2 `straggler` advisories.

## Detailed Findings

### P1

**[P1] Generic theme, no Fiber identity**
- Location: `src/styles/globals.css`, `tailwind.config.ts`, `components/layout/sidebar.tsx`, `public/favicon.svg`
- Category: Theming / Implementation Integrity
- Impact: Product reads as a template; forks get no reference for how a branded theme should be wired.
- Recommendation: Map Fiber's Figma palette (purple `#9D78F0` scale, `#FAF8FE` canvas, `#E8E8E8` border, `#1E1E1E` text) onto the existing semantic tokens. Use purple-700 `#6A48E3` for primary actions (5.8:1 on white; `#9D78F0` is only 3.3:1).
- Suggested command: `/impeccable colorize`

**[P1] Hard-coded status colours bypass tokens**
- Location: 26 files, e.g. `pages/tools/email-validation.tsx`, `pages/tools/phone-validation.tsx`, `pages/exports/index.tsx`, `pages/account/index.tsx`, `components/enrichment/enrichment-result-card.tsx`, `components/search/prospect-table.tsx`
- Category: Theming
- Impact: Theme changes miss these; under `.dark` they render light pills on dark surfaces.
- Recommendation: Add `success` / `warning` / `info` (+ `-foreground`, `-muted`) tokens and replace the palette classes.
- Suggested command: `/impeccable colorize`

**[P1] Desktop-only layout**
- Location: `components/layout/app-layout.tsx`, `components/layout/sidebar.tsx`, `pages/search/companies.tsx:92`, `pages/search/prospects.tsx:86`
- Category: Responsive
- Impact: At 390px the sidebar takes 256px and the filter panel the rest; results are pushed off-screen with no way to reach them.
- Recommendation: Off-canvas sidebar below `md` with a top bar + menu button; stack filter panels above results below `md`.
- Suggested command: `/impeccable adapt`

**[P1] Icon-only buttons have no accessible name**
- Location: 14 `size="icon"` buttons (sidebar collapse toggle, copy, remove, pagination, etc.); 0 `aria-label`s in `src/`
- Category: Accessibility · WCAG 4.1.2 Name, Role, Value
- Impact: Screen readers announce "button" with no purpose.
- Recommendation: `aria-label` on every icon-only button; `aria-current="page"` on the active nav link.
- Suggested command: `/impeccable harden`

**[P1] Unused web font, no deliberate typeface**
- Location: `pages/_document.tsx:9`, `tailwind.config.ts` (no `fontFamily`)
- Category: Performance / Implementation Integrity
- Impact: Render-blocking third-party request for a font that is never used; text falls back to the OS UI font, so the app looks different on every platform.
- Recommendation: Fiber's product face (TWK Lausanne) is licensed and can't ship open source. Self-host an open grotesk stand-in via `@fontsource` behind a `--font-sans` token.
- Suggested command: `/impeccable typeset`

### P2

- **[P2] Heading levels skip h1 → h3** — `components/shared/empty-state.tsx` and section cards. WCAG 1.3.1. → `/impeccable harden`
- **[P2] Active nav state misses sub-routes** — `sidebar.tsx` compares `pathname === href`, so `/audiences/[id]`, `/saved-searches/[id]` etc. highlight nothing. → `/impeccable polish`
- **[P2] Browser surfaces unthemed** — default text selection, scrollbars and caret; tables don't use tabular numerals. → `/impeccable polish`
- **[P2] Muted text on accent surfaces is 4.35:1** — `--muted-foreground` on `--accent` (hover/active rows) misses AA. → `/impeccable colorize`
- **[P2] Disabled primary button looks like a grey block** — `/setup`, `/enrichment/single` before input; reads as broken rather than "waiting for input". → `/impeccable polish`

### P3

- **[P3] Empty-state copy stragglers** — "companies." orphaned on its own line. → `/impeccable polish`
- **[P3] Sidebar links have no custom focus style** — they rely on the browser outline. → `/impeccable polish`

## Patterns & Systemic Issues

- Status colour is chosen ad hoc per page (green/amber/red/blue at different shades) instead of through tokens.
- Icon-only controls never carry labels.
- Layouts assume ≥1024px everywhere; only 40 responsive modifiers across 110 files.

## Positive Findings

- Clean semantic token architecture already in place; a re-theme is mostly a token change.
- Radix primitives give correct roles, focus trapping and keyboard support for dialogs, menus, selects and tooltips.
- Buttons and inputs already have `focus-visible` rings.
- No gradient text, glassmorphism, side-stripe borders or decorative motion — the slop is in omission, not excess.
- No horizontal page scroll on mobile (content is clipped inside the panes instead).

## Recommended Actions

1. **[P1] `/impeccable colorize`** — Fiber palette into tokens; add success/warning/info; replace hard-coded status classes.
2. **[P1] `/impeccable typeset`** — self-hosted open grotesk behind `--font-sans`; drop the Google Fonts Inter link.
3. **[P1] `/impeccable adapt`** — off-canvas sidebar + stacked filter panels below `md`.
4. **[P1] `/impeccable harden`** — aria-labels on icon buttons, `aria-current`, heading order.
5. **[P2] `/impeccable polish`** — nav sub-route matching, selection/scrollbar/caret, tabular numerals, disabled states, stragglers.

Re-run `/impeccable audit` after fixes to see the score improve.
